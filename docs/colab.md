# Colab: four cells, one implementation

Open `notebooks/TamaBench_Colab.ipynb` in Colab. The notebook contains only installation, configuration, execution, and export cells; simulation/provider logic lives in the package.

1. By default, upload the supplied reviewed V2 source ZIP when the first cell opens a file picker. Extraction rejects traversal paths, symlinks, and oversized archives before installing. Alternatively set `LOCAL_CHECKOUT` to a previously uploaded/unpacked checkout, or set `REF` to a reviewed **published** commit/tag containing V2. Prefer a full commit SHA for reproducibility. This unpublished checkout does not pretend a remote V2 release exists.
2. Use the provider dropdown: `cpu` (default), `openai`, `openrouter`, `groq`, `ollama`, or `custom`. For APIs enter your exact model ID; no cloud model is selected for you. Add `OPENAI_API_KEY`, `OPENROUTER_API_KEY`, or `GROQ_API_KEY` in Colab's Secrets panel and enable notebook access. The cell reads the selected secret without printing it and runs a no-network preflight. Custom providers require a base URL; the optional key-variable field is a variable name, never a key value. See [provider details](providers.md). The initial run is a 240-minute, one-seed smoke test with 30 API calls, 512 output tokens per call, 30,000 observed total tokens, five minutes wall time, and no model-output retries. Adjust these explicitly for reasoning models and full seven-day multi-seed comparisons. Hosted APIs need no Colab GPU and may incur charges. Optional Drive mounting persists the whole output bundle. Ollama must be running and supplied with a model separately.
3. Execute the same `run_experiment(config)` used by the CLI. `resume=True` skips finished exact config/seed pairs, including scientific failures, and restarts infrastructure interruptions. Configuration/source changes intentionally invalidate the match.
4. Archive the output directory and download the ZIP. If Drive is enabled, the original bundle also remains in Drive. Inspect the manifest, JSON/CSV/Markdown summaries, SQLite results, and traces.

No real provider, GPU, Drive authentication, or Colab session was exercised by the local notebook tests. They validate the four code cells, syntax, package delegation, CPU smoke path, and each named API profile with Colab interfaces and HTTP responses stubbed out. Source ZIP upload, dependency installation, and download require a live Colab session when you choose to run it.
