# README brand assets

`chevalabs-logo.png` is the existing Cheva Labs mark, reused unchanged from the project’s established brand assets. The Cheva Labs website identifies the same mark as `/logo.png` at <https://chevalabs.net/logo.png>. It is the Cheva Labs brand mark, not a newly generated substitute.

The two SVG headers are self-contained compositions for light and dark GitHub themes. Both embed the exact PNG bytes without recoloring or redrawing the mark. All other shapes and text are repository-local vector artwork. The seven dots refer to the benchmark’s seven-day horizon; they do not represent measured results.

No remote fonts, scripts, tracking pixels, or external image dependencies are used in the headers. The logo remains the property of its owner; its presence here does not grant third-party trademark rights.
